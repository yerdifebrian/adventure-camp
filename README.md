- ## Deskripsi Program
Adventure Camp adalah aplikasi berbasis console yang dibuat dengan bahasa C
untuk membantu pencatatan penyewaan peralatan camping. Program menghitung
biaya sewa secara otomatis berdasarkan jenis peralatan, jumlah unit, dan
lama penyewaan, lalu memberikan diskon sesuai ketentuan (3-4 hari 10%,
5 hari atau lebih 15%).

### Fitur
- Menampilkan daftar peralatan beserta harga sewa per hari
- Memproses penyewaan dan mencetak struk transaksi
- Menyimpan riwayat transaksi (maksimal 10) beserta jumlah transaksi dan total pendapatan
- Validasi input, sehingga pengguna diminta mengulang jika masukan tidak sesuai
- Menu interaktif yang terus tampil sampai pengguna memilih keluar

### Konsep yang Digunakan
Percabangan (if-else, switch-case), perulangan (while, do-while, for),
array, fungsi, dan pemrograman terstruktur.
